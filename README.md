# bricklink item image obtainer
an easy-to-use autohotkey-based program that allows you to obtain itemimage links for any items available on the bricklink website.

# dependecies required
[`autohotkey`](https://autohotkey.com/): more specifically version 1.1, i have not tested this script in any way in version 2.0

# how to use
- first, either open the "main.ahk" (main itemimage obtainer) or "main_extn.ahk" (extn itemimage obtainer) scripts.
- second, visit [`bricklink.com`](https://www.bricklink.com/catalog.asp) on any browser, search for an item you want to obtain the itemimage for, and then copy it's ID.
- third, copy the item ID onto the "Item ID" text field (or copy the **Number ID** for the extn image in the **"main_extn.ahk"** script, then specify the file extension (can either be .jpg or .gif), size, and item type for the itemimage to obtain **(this only works for the main.ahk script)**.
- finally, press **F1** to copy the item image link onto your clipboard and visit the copied link on your browser to see the itemimage you have obtained.
