# bricklink item image obtainer
an easy-to-use autohotkey-based program that allows you to obtain itemimage links for any items available (such as parts, minifigures, gear, books, catalogs, set box & instructions, and extn images) on the bricklink website.

# dependecies required
[`autohotkey`](https://autohotkey.com/): more specifically version 1.1, i have not tested this script in any way in version 2.0

# how to use
- first, open the **"main.ahk"** (itemimage obtainer) script.
- second, visit [`bricklink.com`](https://www.bricklink.com/catalog.asp) on any browser, search for an item you want to obtain the itemimage for, and then copy it's item number, or EXTN number for the EXTN image.
- third, specify the item type in the "Item Type" dropdown menu (can either be **G:** gear, **M:** minifigure, **P:** part, **S:** LEGO set, **B:** book, **C:** catalog, **O:** original lego set box, **I:** lego set instructions, or **T:** EXTN image).
- fourth, copy the item number onto the "Item Number" text field (or copy the **EXTN Number ID** for the extn image with the **T** item type chosen), then specify the file extension (can either be .jpg or .gif), and image size (can either be large or small).
- finally, press **F1** to copy the item image link onto your clipboard and visit the copied link on your browser to see the itemimage you have obtained.
